# 前端设计规范

## 1. 设计理念

### 1.1 核心设计原则
- **简洁明了**：界面设计简洁清晰，避免不必要的元素和干扰，让用户能够快速理解和操作
- **专业美观**：采用现代设计风格，使用专业的色彩方案和排版，提升应用的视觉美感
- **用户友好**：以用户为中心，提供直观的交互体验，减少学习成本
- **响应式设计**：确保在不同设备上都能提供良好的用户体验
- **一致性**：保持设计语言的一致性，包括色彩、排版、组件样式等

### 1.2 目标用户
- **技术人员**：需要监控和管理智能体协作的技术人员
- **管理人员**：需要了解系统运行状态和性能指标的管理人员
- **开发人员**：需要调试和优化系统的开发人员

## 3. 排版规范

### 3.1 字体选择
- **主要字体**：`font-sans` - 无衬线字体，现代简洁
- **字体粗细**：使用 `font-medium`、`font-semibold`、`font-bold` 等工具类

### 3.2 字体大小
- **标题 1**：`text-2xl md:text-3xl lg:text-4xl font-bold` - 用于页面标题
- **标题 2**：`text-xl md:text-2xl lg:text-3xl font-bold` - 用于卡片标题
- **标题 3**：`text-lg md:text-xl lg:text-2xl` - 用于副标题
- **标题 4**：`text-base md:text-lg lg:text-xl` - 用于小标题
- **正文**：`text-sm md:text-base` - 用于普通文本
- **小字**：`text-xs md:text-sm` - 用于辅助文本

### 3.3 行高和间距
- **行高**：使用 `leading-relaxed` 等工具类，确保文本可读性
- **间距**：使用 `spacing-responsive` 等工具类，确保元素间的合理间距

## 4. 组件设计

### 4.1 卡片组件
- **基础卡片**：`.card` - 白色背景，圆角，阴影，边框
- **渐变卡片**：`.card-gradient` - 渐变背景，圆角，阴影，边框
- **强调卡片**：`.card-accent` - 强调样式，圆角，阴影，边框
- **交互卡片**：`.card-interactive` - 包含悬停效果和阴影效果

### 4.2 按钮组件
- **基础按钮**：`.btn` - 基础样式，圆角，过渡效果
- **主按钮**：`.btn-primary` - 主色调，白色文本
- **渐变按钮**：`.btn-primary-gradient` - 渐变背景，白色文本
- **次要按钮**：`.btn-secondary` - 灰色背景，深色文本
- **危险按钮**：`.btn-danger` - 红色背景，白色文本
- **成功按钮**：`.btn-success` - 绿色背景，白色文本
- **轮廓按钮**：`.btn-outline` - 边框样式，透明背景
- **交互按钮**：`.btn-interactive` - 包含悬停效果和焦点效果

### 4.3 输入框组件
- **基础输入框**：`.input` - 基础样式，圆角，边框
- **小输入框**：`.input-sm` - 较小的输入框
- **大输入框**：`.input-lg` - 较大的输入框
- **圆形输入框**：`.input-rounded` - 圆形样式
- **错误输入框**：`.input-error` - 错误状态，红色边框
- **成功输入框**：`.input-success` - 成功状态，绿色边框
- **交互输入框**：`.input-interactive` - 包含悬停效果和焦点效果

### 4.4 图标组件
- **基础图标**：`AppIcon` - 统一的图标组件
- **图标大小**：支持 `sm`、`md`、`lg`、`xl` 四种尺寸
- **图标颜色**：支持多种颜色变体

### 4.5 状态组件
- **状态徽章**：`.status-badge` - 用于显示状态
- **成功徽章**：`.status-badge-success` - 成功状态
- **警告徽章**：`.status-badge-warning` - 警告状态
- **危险徽章**：`.status-badge-danger` - 危险状态
- **信息徽章**：`.status-badge-info` - 信息状态

## 5. 布局设计

### 5.1 容器布局
- **响应式容器**：`.responsive-container` - 适配不同屏幕尺寸
- **最大宽度**：使用 `container` 类，确保内容在大屏幕上不会过宽
- **内边距**：使用 `px-4 sm:px-6 lg:px-8 xl:px-12` 等工具类，确保内容与边缘的合理间距

### 5.2 网格布局
- **响应式网格**：`.responsive-grid` - 适配不同屏幕尺寸
- **两列网格**：`.responsive-grid-2` - 两列布局
- **四列网格**：`.responsive-grid-4` - 四列布局
- **间距**：使用 `gap-4 sm:gap-6` 等工具类，确保网格项之间的合理间距

### 5.3 响应式设计
- **移动端**：`sm:` 前缀以下的样式
- **平板端**：`md:` 前缀的样式
- **桌面端**：`lg:` 前缀的样式
- **大屏幕**：`xl:` 前缀的样式

## 9. 设计规范执行

### 9.1 代码规范
- **使用 Tailwind CSS**：优先使用 Tailwind CSS 工具类
- **避免内联样式**：尽量不使用内联样式
- **组件复用**：使用组件化开发，提高代码复用率
- **命名规范**：使用语义化的类名和变量名

### 9.2 设计一致性
- **遵循设计规范**：严格遵循本设计规范
- **定期审查**：定期审查代码和设计，确保一致性
- **持续优化**：根据用户反馈和使用情况，持续优化设计
